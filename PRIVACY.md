# GetYourSats privacy

Read the [GetYourSats privacy notice](https://getyoursats.com/privacy) for information about wallet and payment data, optional account services, support requests and removal requests.

The public notice is maintained in [site/privacy.html](site/privacy.html), with a wallet-hosted copy in [public/privacy.html](public/privacy.html). Changes to data handling must update the notice and both published copies together. A draft integration is not evidence that a service is enabled.

For a privacy request, use [GetYourSats Support](https://getyoursats.com/support#contact) and select **Privacy & data requests**. Never submit recovery words, private keys or authentication credentials. Removing browser data does not automatically remove server-held records or public blockchain transactions.

The upstream Glow privacy policy describes a different product and is not the privacy notice for GetYourSats.
