# Release readiness

Use the maintained [release-readiness checklist](docs/maintainers/release-readiness.md) and [deployment guide](docs/maintainers/deployment.md). Complete them with evidence for the exact candidate commit and SDK revision.

The earlier [23 October release audit](docs/archive/release-audit-20261023.md) remains available as a historical record. Its account-access notes, integrations and unchecked items must not be treated as the current release state.
